Conectar a fábrica

O painel precisa de uma chave do GitHub para ver e comandar a sua fábrica. Ela fica salva só neste aparelho.

  1. Toque em Criar a chave no GitHub.
  2. Em Repository access, escolha Only select repositories › canaldark.
  3. Confira em Permissions: Actions e Contents com Read and write.
  4. Toque em Generate token, copie a chave e cole aqui embaixo.
